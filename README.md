### MAIN – DESCRIPCIÓN DE LA APLICACIÓN

La aplicación **MiniShop** es una tienda móvil sencilla desarrollada con **React Native y TypeScript**, que permite visualizar productos, agregarlos a un carrito de compras, eliminarlos y realizar una compra.

El usuario puede consultar productos como camisetas, gorras y mochilas, cada uno con su respectivo precio. Al seleccionar **“+ Agregar”**, el producto se incorpora al carrito y se actualiza automáticamente la cantidad de productos. En la sección **“Mi carrito”**, el usuario puede revisar los productos seleccionados, consultar el total de la compra y eliminar productos que ya no desea.

Finalmente, al presionar **“Comprar”**, la aplicación verifica que el carrito no esté vacío, muestra una confirmación con el total de la compra y limpia el carrito para iniciar una nueva compra.

La interfaz utiliza una **temática de colores verdes**, botones interactivos y una estructura sencilla para ofrecer una experiencia de compra fácil y rápida desde un dispositivo móvil.
